# ⚗️ ครูวิ สอนวิทย์ | KRU WI SCIENCE LAB

**เว็บไซต์สื่อการเรียนรู้วิทยาศาสตร์ ม.1–ม.3 และติว O-NET วิทยาศาสตร์เฉพาะ ม.3** พร้อมเผยแพร่บน GitHub + Cloudflare Pages

## ฟีเจอร์

- 🌱 บทเรียนวิทยาศาสตร์ 9 เรื่อง: ม.1–ม.3 พร้อมค้นหาและกรองระดับชั้น
- 🧪 ห้องทดลองเปลี่ยนสถานะน้ำแบบ Interactive และคู่มือกิจกรรมเพิ่มเติม
- ✅ แบบทดสอบทบทวน ม.1, ม.2, ม.3 อย่างละ 5 ข้อพร้อมเฉลย
- 📝 ใบงาน A4 จำนวน 3 ชุด ดูตัวอย่างและสั่งพิมพ์ได้
- 🎯 **O-NET ม.3** คลังข้อฝึกสร้างใหม่ 48 ข้อ แบ่ง 4 สาระ
- 📚 โหมดฝึก 8 ข้อ (ทุกสาระ) หรือ 6 ข้อ (สาระเดียว) พร้อมเฉลยทันที
- ⏱️ โหมดจำลองข้อสอบ 20 ข้อ / 40 นาที พร้อมจับเวลา ส่งเมื่อหมดเวลา และเรียกคืนชุดสอบค้างหลัง Refresh
- 📊 สถิติคะแนนย้อนหลัง กราฟแนวโน้ม วิเคราะห์รายสาระ ตรวจเฉลยย้อนหลัง และส่งออกประวัติเป็น CSV
- 🏅 ระดับความก้าวหน้า Beginner / Explorer / Scientist / Science Master ตามจำนวนรอบการฝึก
- ✏️ **เครื่องมือครู** เพิ่ม แก้ ลบ ข้อสอบ ส่งออกไฟล์ `onet-bank.js` สำหรับอัปเดต GitHub (ไม่ใช่ Admin ที่มีการล็อกอิน)
- 🌙 โหมดมืด รองรับมือถือและแท็บเล็ต

**เปิดบนเครื่อง:** เปิด `index.html` ในเบราว์เซอร์

**Deploy:** ดูคำแนะนำทีละขั้นตอนใน [DEPLOY.md](DEPLOY.md) — ใช้ GitHub และ Cloudflare Pages แบบ Git integration โดยไม่ต้อง Build

## โครงสร้างไฟล์

```text
index.html        หน้านักเรียน
styles.css        สไตล์เว็บหลัก
app.js            บทเรียน/ห้องทดลอง/ใบงาน/แบบทดสอบ
onet.css          สไตล์โหมดติว
onet.js           Exam Engine + สถิติและประวัติ
onet-bank.js      คลังโจทย์ O-NET ม.3 (แก้ได้จากเครื่องมือครู)
teacher.html      หน้าแก้ไขคลังข้อสอบแบบ Local-only
teacher.css       สไตล์หน้าครู
teacher.js        ตัวแก้ไขโจทย์ + Import/Export
favicon.svg       โลโก้สัญลักษณ์
DEPLOY.md         คู่มือ GitHub + Cloudflare Pages
.github/workflows/quality.yml  ตรวจความครบถ้วนของข้อสอบด้วย GitHub Actions
scripts/check.mjs คำสั่งทดสอบแบบไม่ต้องติดตั้งแพ็กเกจ
```

## สำคัญ

- ไม่มี Backend หรือระบบล็อกอินในเวอร์ชันนี้ คะแนน/ความก้าวหน้าใช้ `localStorage` เก็บบนเครื่องนักเรียนเท่านั้น
- เครื่องมือครูไม่ได้อัปเดต GitHub โดยตรง ต้องนำไฟล์ที่ดาวน์โหลดไป Commit ด้วยบัญชีที่มีสิทธิ์
- เนื้อหา O-NET ทั้งหมดเป็นข้อฝึกสร้างใหม่ ไม่ใช่ข้อสอบจริงของ สทศ. จำนวนข้อและเวลาจำลองเป็นรูปแบบเพื่อการฝึกเท่านั้น
- รายละเอียดโครงสร้างข้อสอบทางการ ดู [สทศ. O-NET ม.3 ปีการศึกษา 2569](https://www.niets.or.th/th/catalog/view/213)

## สำหรับนักพัฒนา

ใช้ HTML/CSS/Vanilla JS ไม่มี dependencies ที่ต้องติดตั้ง สามารถใช้ `node scripts/check.mjs` ทดสอบข้อมูลและอ้างอิงไฟล์ก่อนนำขึ้น GitHub ได้
