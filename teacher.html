วิธีเผยแพร่ข้อสอบที่แก้ไขแล้ว

  1. แก้ไขโจทย์ในหน้านี้ แล้วคลิก บันทึกฉบับร่าง ทุกครั้ง
  2. คลิก ดาวน์โหลด onet-bank.js เพื่อรับไฟล์คลังโจทย์ล่าสุด
  3. เข้า GitHub Repository ของเว็บไซต์ครูวิ เปิดไฟล์ onet-bank.js แล้วแทนเนื้อหาด้วยไฟล์ที่ดาวน์โหลด (หรืออัปโหลดทับผ่าน Git)
  4. Commit การแก้ไขลงสาขา main — Cloudflare Pages จะเผยแพร่เว็บใหม่ตามการตั้งค่าการเชื่อม Git
